WordFreq プライバシーポリシー

最終更新日: 2026年11月3日

WordFreq（以下「本拡張機能」）は、選択した英単語の使用頻度を表示する Chrome 拡張機能です。 本拡張機能は、取り扱う情報をすべて利用者の端末内で処理し、外部へ送信しません。

1. 取り扱う情報

本拡張機能は、機能の提供のために次の情報を取り扱います。いずれも端末内（chrome.storage.local）にのみ保存され、外部へ送信されません。

情報内容保存
選択した文字列 頻度を調べるために、利用者が選択した文字列を読み取ります 調べた語として履歴に保存
設定 自動表示のオン/オフ、サイトごとの表示設定、表示モード 保存する
履歴 調べた単語、その頻度（Zipf 値）、順位、時刻。最大50件 保存する

アクセス解析・広告・トラッキングは行いません。

2. ページの内容の扱い

本拡張機能は、利用者が選択した文字列だけを読み取ります。ページ全体の内容を読み取ったり保存したりすることはありません。 読み取った文字列は、同梱の頻度データと照合するためだけに使用します。

3. 保存した情報の削除

履歴はポップアップの「消す」から削除できます。設定を含むすべての保存データは、ブラウザの拡張機能データの削除、または本拡張機能のアンインストールで削除されます。

4. 第三者への提供

本拡張機能は、取り扱う情報を第三者へ提供しません。外部のサーバーとの通信も行いません。

5. 権限の利用目的

権限用途
storage設定と履歴をブラウザ内に保存するため
contextMenus右クリックメニュー（頻度の表示、サイトごとのオン/オフ）のため
すべてのサイトへのアクセス任意のページで選択を検知し、カードを表示するため

6. Limited Use（限定的な使用）

本拡張機能によるデータの取り扱いは、Chrome Web Store のユーザーデータポリシーに定める Limited Use の要件に従います。

  • データは、単一の目的（選択した単語の頻度表示）を提供するためだけに使用します
  • 広告の配信、プロファイリング、データの販売を行いません
  • 開発者を含む人間が、利用者のデータを読み取ることはありません
  • 法令に基づく場合を除き、第三者へ転送しません
